# Digital Craft

Build a modern, highly responsive, and premium portfolio website for a full-stack web developer and automation expert.

Visual Style & UI/UX:

Color Palette: Sophisticated dark mode. Use a deep graphite background (#1A1A1A to #222222), crisp white/light gray for typography, and champagne/muted gold (#F2E3C6 or similar) for primary accents, buttons, and hover states.

Aesthetic: Clean, minimalist, and highly legible with plenty of whitespace. Premium feel.

Tech: Use Tailwind CSS for styling, lucide-react for modern icons, and Framer Motion (or pure CSS) for smooth, subtle reveal animations on scroll.

Page Structure:

1. Navigation Bar:

Left: Developer Name/Logo (Text).

Center: Links (Services, Work, Contact).

Right: A CTA button "Message in Telegram". Sticky navbar with a slight glassmorphism effect on scroll.

2. Hero Section:

Headline: "Building Web Apps, Telegram Bots & Business Automations."

Subheadline: "I design fast landing pages, engineer complex Telegram Web Apps, and seamlessly integrate APIs to automate your business processes."

CTAs: Two buttons side-by-side. Primary (Champagne color): "View My Work". Secondary (Outline): "Let's Talk".

3. Services Section (3-Column Grid):

Card 1 (Landing Pages & Web Apps): Monitor icon. Focus on high-converting UI and fast performance.

Card 2 (Telegram Bots & Web Apps): Smartphone/Bot icon. Focus on custom Python/Node.js bots and seamless mini-apps for scheduling and booking.

Card 3 (Business Automation): Database/Cog icon. Focus on Airtable/Supabase integrations, API webhooks, and optimizing workflows.

Add subtle hover effects to lift the cards slightly.

4. Portfolio / Projects Showcase (Grid Layout):

Create 4 sample project cards (e.g., "Food Delivery Web App", "Barbershop Telegram Mini App", "Airtable CRM Sync").

Card Anatomy: Image placeholder (use a clean geometric or abstract gradient placeholder), Project Title, a short descriptive paragraph, and a row of Tech Stack tags (e.g., React, Node.js, Python, Supabase, Airtable).

Interaction: Include a "View Project" link with a nice arrow icon that animates on hover.

5. Footer:

Minimalistic. "Ready to automate your workflow?" text.

Social links (GitHub, Telegram, Email).

Copyright year.

Make sure the layout is fully responsive for mobile devices, breaking down grids into single columns neatly.
